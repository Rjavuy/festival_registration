# Система регистрации участников фестиваля

## Назначение

Приложение для автоматизации подачи и обработки заявок на участие
в фестивале. Участники отправляют заявки, организаторы их проверяют
и присваивают статус.

## Целевая аудитория

- Участники фестиваля (артисты, волонтёры, гости).
- Организаторы и администраторы фестиваля.

## Предметная область

Организация и проведение массовых мероприятий (фестивалей).

## Основные сущности

- Участник
- Фестиваль
- Заявка
- Статус

## Основные функции

- Проверка возможности подачи заявки (возраст, дедлайн, количество мест).
- Валидация email участника.
- Валидация телефона участника.
- Валидация даты рождения.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей (участники и организаторы);
- разработка API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
